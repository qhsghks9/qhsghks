# 기회 단계: Lead → Stage 0 → Stage 1

> 출처: AX컨설팅팀 교육 자료 (2026-10-22 공유)
> 관련: `01_요청을_기회근거로_전환.md`, `02_신뢰를_주는_증거.md`

```
Lead (Signal)  →  Stage 0 (Evidence)  →  Stage 1 (Credible opportunity)
   신호               증거                   신뢰할 수 있는 기회
```

이 단계들을 활용해 해당 기회에 대해 **얼마나 확신을 가지고 있는지** 파악한다.

| 기회 상태 | 의미 | 일반적으로 알려진 사항 |
|---|---|---|
| **리드 (Lead)** | 잠재적인 AI 기회가 존재할 수 있다는 가장 초기 징후 | 고객의 관심이 있거나 잠재적인 문제 영역이 존재하지만, 기회는 아직 명확하지 않음 |
| **0단계 (Stage 0)** | 기회가 실제로 존재하며 진행할 준비가 되어 있는지 체계적으로 검증하는 단계 | 문제가 더 구체화되고, 타당한 사용 사례가 드러나며, 이해관계자나 다음 단계가 가시화되고 있음 |
| **1단계 (Stage 1)** | 기회에 대해 더 심층적인 공동 작업을 진행할 만한 충분한 근거가 있음 | 고객의 문제, 관련 이해관계자, AI를 탐구할 가치가 있는 이유, 타당한 다음 단계가 체계적인 기회 개발을 뒷받침할 만큼 충분히 명확해짐 |

## 단계 전환 기준 (02 문서의 5가지 질문 활용)
| 전환 | 충족되어야 할 증거 |
|---|---|
| Lead → Stage 0 | 관심/문제 영역이 확인되어 **검증할 가치**가 있음 (질문 1이 부분적으로라도 답해짐) |
| Stage 0 → Stage 1 | 5가지 질문(문제 명확성·워크플로우·이해관계자·타당한 방향·다음 단계 합의)에 **모두 근거 있는 답**이 있음 |

## 컨설팅 적용
- 파이프라인의 각 고객 건에 현재 단계(Lead / Stage 0 / Stage 1)를 표기하고, 단계 판단의 근거를 함께 기록한다.
- "AI 해보고 싶다"는 말만 있는 건은 **Lead**로 두고, 01 문서의 6가지 항목을 조사하며 Stage 0로 끌어올린다.
- Stage 1 이전에 큰 제안서·PoC에 리소스를 투입하지 않는다.
