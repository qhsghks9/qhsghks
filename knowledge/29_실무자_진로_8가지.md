# 8가지 실무자 진로

> 출처: AX컨설팅팀 교육 자료 (2026-10-22 공유) — 원문은 OpenAI 파트너 교육 기준. 슬라이드에는 진로 이름만 있고 설명은 없음
> 관련: `25_솔루션_형태를_정하는_질문.md`, `26_업무_인계_구조.md`, `27_판매자의_결정_범위와_검증_요청.md`, `28_세_가지_결정_순서.md`

8가지 실무자 진로는 다음과 같다.

1. **OpenAI 컨설팅 솔루션 실무자**
2. **ChatGPT 솔루션 실무자**
3. **Codex 솔루션 실무자**
4. **ChatGPT 배포 실무자**
5. **OpenAI 기술 실무자**
6. **Codex 배포 실무자**
7. **API 배포 전문가**
8. **OpenAI 사이버 실무자**

## 상업 및 솔루션 포지셔닝 경로 (3가지)
다음 세 가지 실무자 경로는 **고객 기회를 파악하고, 형성하며, 포지셔닝**하는 데 중점을 둔다.

| 경로 | 중점 |
|---|---|
| **OpenAI 컨설팅 솔루션 실무자** | 발굴, 적격성 평가, 사용 사례 설계, 가치, 솔루션 라우팅, 산업적 맥락 및 초기 기회 추진에 걸쳐 **폭넓은 상업적 역량**을 구축한다 |
| **ChatGPT 솔루션 실무자** | ChatGPT 솔루션 적합성, 워크플로 설계, 비즈니스 포지셔닝, 기회 준비도, 업무 인계, 그리고 **실제 고객 대화 실습**에 중점을 둔다 |
| **Codex 솔루션 실무자** | Codex의 기회 적합성, 포지셔닝, 비즈니스 가치, **소프트웨어 개발 사용 사례**, 신뢰, 도입 및 **실제 고객 대화 실습**에 중점을 둔다 |

> 이 교육 자료(01~28 문서)의 내용 — 기회 발굴(01~08), 디스커버리(09~14), 사용 사례 설계(15~19), 가치(20~22), 솔루션 라우팅·인계(23~28) — 은 **OpenAI 컨설팅 솔루션 실무자** 경로의 범위와 거의 그대로 겹친다. (참고용 정리)

### 구조 정리 (참고용 정리)
- 두 자격 모두 **공통 기반 2개** = 컨설팅 솔루션 실무자 + 기술 실무자.
- 여기에 제품별 **솔루션 + 배포** 실무자 2개를 더한다 (ChatGPT 또는 Codex).
- 즉 Advanced 자격은 **상업(컨설팅·솔루션) + 기술 + 배포**를 모두 갖춘 사람을 의미한다.
- 8개 진로 중 **API 배포 전문가**와 **OpenAI 사이버 실무자**는 이 두 Advanced 자격 구성에 포함되지 않는다 (별도 자격이 있을 수 있음 — 이미지 위쪽에 다른 자격 카드가 잘려 있음).

## 컨설팅 적용 (참고용 정리)
- 28 문서 ③ 다음 단계에서 **"기술적 또는 배포 인계"** 를 고를 때, 인계 대상 역할을 이 진로 기준으로 정할 수 있다. 예: 고객이 API 연동 아키텍처를 요구 → API 배포 전문가 / 보안·규제 민감 워크플로우 → 사이버·기술 실무자.
- AX컨설팅팀의 역량 계획이나 자격 취득 로드맵을 세울 때 참고할 수 있다. 각 진로의 정확한 요건과 범위는 원 교육 자료나 OpenAI 파트너 프로그램 안내에서 확인해야 한다.
