# 8가지 실무자 진로

> 출처: AX컨설팅팀 교육 자료 (2026-10-22 공유) — 원문은 OpenAI 파트너 교육 기준. 슬라이드에는 진로 이름만 있고 설명은 없음
> 관련: `25_솔루션_형태를_정하는_질문.md`, `26_업무_인계_구조.md`, `27_판매자의_결정_범위와_검증_요청.md`, `28_세_가지_결정_순서.md`

8가지 실무자 진로는 다음과 같다.

1. **OpenAI 컨설팅 솔루션 실무자**
2. **ChatGPT 솔루션 실무자**
3. **Codex 솔루션 실무자**
4. **ChatGPT 배포 실무자**
5. **OpenAI 기술 실무자**
6. **Codex 배포 실무자**
7. **API 배포 전문가**
8. **OpenAI 사이버 실무자**

## 상업 및 솔루션 포지셔닝 경로 (3가지)
다음 세 가지 실무자 경로는 **고객 기회를 파악하고, 형성하며, 포지셔닝**하는 데 중점을 둔다.

| 경로 | 중점 |
|---|---|
| **OpenAI 컨설팅 솔루션 실무자** | 발굴, 적격성 평가, 사용 사례 설계, 가치, 솔루션 라우팅, 산업적 맥락 및 초기 기회 추진에 걸쳐 **폭넓은 상업적 역량**을 구축한다 |
| **ChatGPT 솔루션 실무자** | ChatGPT 솔루션 적합성, 워크플로 설계, 비즈니스 포지셔닝, 기회 준비도, 업무 인계, 그리고 **실제 고객 대화 실습**에 중점을 둔다 |
| **Codex 솔루션 실무자** | Codex의 기회 적합성, 포지셔닝, 비즈니스 가치, **소프트웨어 개발 사용 사례**, 신뢰, 도입 및 **실제 고객 대화 실습**에 중점을 둔다 |

> 이 교육 자료(01~28 문서)의 내용 — 기회 발굴(01~08), 디스커버리(09~14), 사용 사례 설계(15~19), 가치(20~22), 솔루션 라우팅·인계(23~28) — 은 **OpenAI 컨설팅 솔루션 실무자** 경로의 범위와 거의 그대로 겹친다. (참고용 정리)

## 개인 자격(Individual designation): Advanced Practitioner 4종

| 자격 | 이수할 실무자 프로그램 (순서 무관) | 최종 요건 (둘 다 이수) |
|---|---|---|
| **OpenAI Advanced ChatGPT Practitioner** | ① OpenAI Consultative Solutions Practitioner ② OpenAI Technical Practitioner ③ ChatGPT Solutions Practitioner ④ ChatGPT Deployment Practitioner | Capstone Project + Final Exam |
| **OpenAI Advanced Codex Practitioner** | ① OpenAI Consultative Solutions Practitioner ② OpenAI Technical Practitioner ③ Codex Solutions Practitioner ④ Codex Deployment Practitioner | Capstone Project + Codex Exam |
| **OpenAI Advanced API Practitioner** | ① OpenAI Consultative Solutions Practitioner ② OpenAI Technical Practitioner ③ API Deployment Practitioner ④ Codex Deployment Practitioner | Capstone Project + Final Exam |
| **OpenAI Advanced Cyber Practitioner** (5개) | ① Codex Solutions Practitioner ② Codex Deployment Practitioner ③ OpenAI Cyber Solutions Practitioner ④ OpenAI Cyber Deployment Practitioner ⑤ OpenAI Advanced Cyber Deployment Practitioner | Capstone Project + Final Exam |

### 최종 요건
| 요건 | 구분 | 내용 |
|---|---|---|
| **Capstone project** | 적용 요건 (Applied requirement) | 시나리오 기반 프로젝트를 수행하고, 마지막에 **적용된 판단력(applied judgment)** 을 보여주는 산출물을 제출한다 |
| **Final exam** | 지식 요건 (Knowledge requirement) | 고급 트랙 **전체**에 걸친 지식을 입증한다. 시험 문제는 해당 자격에 포함된 **모든 실무자 프로그램 내용**에서 출제될 수 있다 |

### 구조 정리 (참고용 정리)
- **ChatGPT·Codex·API** 자격은 공통 기반 2개(**컨설팅 솔루션 + 기술 실무자**)에 제품별 프로그램 2개를 더하는 구조다.
  - API 자격은 솔루션 과정 대신 **API 배포 + Codex 배포** 두 배포 과정으로 구성된다.
- **Cyber** 자격은 공통 기반 없이 **Codex 솔루션·배포 + 사이버 솔루션·배포·고급 배포** 5개로 구성된다. 즉 보안 업무에 Codex를 적용하는 트랙으로 보인다.
- 앞의 "8가지 실무자 진로" 목록의 **"OpenAI 사이버 실무자"** 는 자격 페이지에서 **Cyber Solutions / Cyber Deployment / Advanced Cyber Deployment** 3개 프로그램으로 나뉘어 있다.
- **Codex Deployment Practitioner** 는 Codex·API·Cyber 세 자격에 공통으로 들어간다. **Consultative Solutions Practitioner** 는 Cyber를 제외한 세 자격에 공통이다.
- Capstone의 "적용된 판단력"은 이 교육 자료 전반의 원칙(증거·가정 구분, 결정 범위, 인계)과 맞닿아 있다.

### 팀 역량 로드맵 예시 (참고용 정리)
1. 공통: **컨설팅 솔루션 실무자**(이 knowledge 폴더 01~28 내용) → **기술 실무자**
2. 주력 방향 선택:
   - 업무용 AI 도입 고객 중심 → ChatGPT 솔루션·배포 (Advanced ChatGPT)
   - 개발 조직 고객 중심 → Codex 솔루션·배포 (Advanced Codex)
   - 맞춤형 애플리케이션·시스템 연동 중심 → API 배포 + Codex 배포 (Advanced API)
   - 보안 조직 고객 중심 → Codex 솔루션·배포 + 사이버 3과정 (Advanced Cyber)
3. 최종: Capstone Project + 시험으로 Advanced 자격 취득
4. Codex 배포 과정은 Codex·API·Cyber 자격에 공통이므로, 여러 자격을 노린다면 먼저 이수하면 효율적이다.

## 구조로 읽기 (참고용 정리 — 솔루션 3경로는 원문으로 확인됨, 나머지 5경로는 이름에서 추정)

- 25 문서 질문 1의 **인터페이스 선택지(ChatGPT·Codex·API)** 와 진로 이름이 대응한다.
- "솔루션" 진로는 이 교육 자료(01~28 문서)에서 다룬 **기회 발굴·디스커버리·사용 사례·가치 스토리** 역할에 가깝고, "배포"·"기술"·"사이버" 진로는 27 문서에서 판매자가 **결정하지 말고 검증을 요청해야 하는 영역**(아키텍처, 배포, 보안)을 맡는 역할로 보인다.

## 컨설팅 적용 (참고용 정리)
- 28 문서 ③ 다음 단계에서 **"기술적 또는 배포 인계"** 를 고를 때, 인계 대상 역할을 이 진로 기준으로 정할 수 있다. 예: 고객이 API 연동 아키텍처를 요구 → API 배포 전문가 / 보안·규제 민감 워크플로우 → 사이버·기술 실무자.
- AX컨설팅팀의 역량 계획이나 자격 취득 로드맵을 세울 때 참고할 수 있다. 각 진로의 정확한 요건과 범위는 원 교육 자료나 OpenAI 파트너 프로그램 안내에서 확인해야 한다.
